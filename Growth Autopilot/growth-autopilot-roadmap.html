00 · Visión del producto

La PYME no debería tener que volverse experta
para crecer bien.

Growth Autopilot es un sistema AI-First que detecta oportunidades y riesgos en el negocio, entiende el contexto del cliente, recomienda la siguiente mejor acción, la ejecuta con control humano, y mide si realmente generó valor incremental.

§1 El problema

Las PYMES tienen información fragmentada y reaccionan tarde: caída de ventas, clientes inactivos, cartera vencida, señales de churn, leads sin seguimiento, comunicaciones genéricas. Los sistemas tradicionales registran eventos — no deciden. Growth Autopilot cierra ese ciclo.

§3 ICP & Job To Be Done

Empresa objetivo

PYME con ventas recurrentes, histórico transaccional, clientes identificables, frecuencia de compra medible, capacidad de comunicación digital y suficiente volumen para aprender patrones.

Usuario principal

Dueño, administrador, gerente comercial o responsable de crecimiento — sin tiempo para revisar múltiples dashboards antes de actuar.

"Cuando tengo cientos o miles de clientes y no sé a quién contactar primero, quiero que el sistema identifique automáticamente las oportunidades con mayor probabilidad de generar ventas." JOB TO BE DONE · USUARIO PRINCIPAL

§12 Tres scores, no uno

§14 Dormancy dinámica

No usar days_since_purchase > 30 para todos. Se calcula contra la frecuencia esperada de cada cliente.

expected_frequency = median_days_between_purchases ratio = days_since_last_purchase / expected_frequency

Umbrales configurables

ratio ≥ 1.5 → warning ratio ≥ 2.0 → dormant

Configurables por tenant / segmento — nunca hardcodeados.

04 · Agentes & Guardrails

No se crean agentes
por estética arquitectónica.

Tres agentes con responsabilidad clara. El LLM explica, redacta y resume — no decide matemáticamente cuál oportunidad priorizar.

Agente A

Growth Orchestrator

Recibe la oportunidad, recupera contexto, aplica política, selecciona workflow, coordina herramientas, gestiona aprobación y registra el resultado.

Agente B

Communication Agent

Genera variantes de comunicación, respeta contexto, personaliza y produce salida estructurada — nunca inventa descuentos, fechas o deuda.

Agente C

Judge Agent

Evalúa el output. No ejecuta negocio — solo decide si algo puede avanzar.
